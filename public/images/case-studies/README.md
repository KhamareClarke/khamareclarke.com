# Case Studies Images

This folder contains images for the case studies carousel.

## Image Requirements
- Format: JPG, PNG, or WebP
- Recommended size: 1200x800px (3:2 aspect ratio)
- Max file size: 500KB for optimal loading

## How to Update

### Adding a New Case Study:
1. Add the company data to `src/app/data/caseStudies.js`
2. Add the corresponding image to this folder
3. Use the image path format: `/images/case-studies/[filename].jpg`

### Updating Existing Case Study:
1. Edit the data in `src/app/data/caseStudies.js`
2. Replace the image in this folder if needed

The carousel will automatically update to reflect your changes!
